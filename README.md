# Credit Risk PD Model

An end-to-end credit risk project focused on estimating the probability of default (PD) and supporting data-driven lending decisions.

## Project status

In development

## Business objective

The project aims to estimate the probability that a newly originated mortgage will experience serious delinquency. The model is intended to support credit risk assessment and portfolio-level risk analysis.

## Target definition

## Target definition

The target will indicate whether a mortgage reaches serious delinquency, defined as 90 or more days past due, within a fixed performance window after origination.

Candidate performance windows of 12, 24, and 36 months will be evaluated based on business relevance, data availability, and the observed default rate.
